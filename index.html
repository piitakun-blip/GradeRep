Report rules

High: grades 9–12 only. Middle: grades 6–8 only. DF: grades 6–12 with a D or F in the letter-grade column. Rows with a blank Running Course Average are deleted; only rows with an actual numeric grade are included. Each Excel table ends at the last actual data row; row 1 stays frozen and includes Excel sort/filter dropdowns; columns A–H remain visible, columns I–XFD are hidden, and rows below the final table row are hidden.

The CSV is processed in your browser. The student data is not uploaded by this page. The CSV reader preserves UTF-8 and common Windows-1252 accented characters. An internet connection is only used to load the Excel/CSV JavaScript libraries.
