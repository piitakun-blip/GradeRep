Report rules

High: grades 9–12 only. Middle: grades 6–8 only. DF: grades 6–12 with a D or F in the letter-grade column. Rows with a blank Running Course Average are deleted; only rows with an actual numeric grade are included. Each Excel table ends at the last actual data row; conditional formatting is applied to the full relevant columns.

The CSV is processed in your browser. The student data is not uploaded by this page. An internet connection is only used to load the Excel/CSV JavaScript libraries.
